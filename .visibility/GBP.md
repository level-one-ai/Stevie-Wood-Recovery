# Google Business Profile: what to enter

Everything below matches the website word for word, so Google sees the same business everywhere. Copy and paste each part into business.google.com → Edit profile.

## Basics

| Field | Enter exactly |
|---|---|
| Business name | `Stevie Wood Recovery` (nothing else. Adding words like "Edinburgh" or "24/7" breaks Google's rules) |
| Primary category | `Towing service` |
| Extra categories | Search and add any of these that appear in the list: `Breakdown service`, `Roadside assistance service`, `Car recovery service`. Only pick ones Google offers |
| Phone | `07934 015448` |
| Website | `https://steviewoodrecovery.com/` |
| Address | `14 Hyvot Bank Ave, Edinburgh EH17 8NJ` (same as the website). If customers never visit this address, Google prefers it hidden and service areas shown instead. Either way, keep the same address saved |
| Hours | Open 24 hours, every day (Monday to Sunday) |
| Special hours | Add Christmas Day, Boxing Day, New Year's Day and 2 January as **Open 24 hours** |
| Service areas | `Edinburgh`, `Musselburgh`, `Dalkeith`, `Bonnyrigg`, `Loanhead`, `Penicuik`, `Midlothian`, `East Lothian`, `West Lothian` |
| Social profiles | Add the Facebook page (Steviewoodrecovery) |
| Opening date | Ask Stevie what year he started trading |

## Ongoing (this is what moves the map ranking)

- After every job, send the customer the review link (Home → Ask for reviews) by WhatsApp. Aim for 4 or more new reviews a month.
- Reply to every review, using the town name where it fits naturally ("Thanks Sarah, glad we got you sorted in Musselburgh").
- Post an update once a week: one job photo and one line about it.
- Check the Q&A section and answer questions using the same answers as the website FAQ.

## Keep these the same everywhere

The Facebook page currently mentions **classic cars** and **light commercial vehicles**, which the website and profile don't. If Stevie does take classic cars, tell us and we'll add it to the website too, so every listing says the same thing.

When the profile is updated, send us its share link and the Facebook page link. We'll add them to the website's hidden business details (`sameAs`), which helps Google connect the website, the profile and Facebook as one business.
